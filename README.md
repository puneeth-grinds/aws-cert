# AWS Certifications

A structured collection of study notes, practice questions, and hands-on learning material for AWS certifications.

## Certifications

### AWS Certified Cloud Practitioner — CLF-C02

Fundamentals of AWS Cloud, including:

* Cloud concepts
* AWS services
* Security and compliance
* Billing and pricing
* AWS Cloud Adoption Framework (CAF)
* Well-Architected Framework

### AWS Certified Solutions Architect — Associate — SAA-C03

Architecture-focused preparation covering:

* AWS core services
* High availability and fault tolerance
* Scalability and elasticity
* Networking
* Storage
* Databases
* Security
* Monitoring
* Cost optimization
* Well-Architected architectures
* Real-world architecture scenarios

## Goal

Build strong AWS fundamentals and develop the ability to design secure, highly available, scalable, and cost-effective solutions on AWS.
